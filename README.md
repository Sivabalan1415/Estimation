# A.S ELECTRICIAN — Material Estimation & Site Procurement System

A modern, mobile-first interactive web application for site electricians, plumbers, and project contractors to prepare, review, and share material estimation lists directly from mobile or desktop.

## 🚀 Features
- **Plumbing & Electrical Catalogs**: Comprehensive master product list including 44 standard plumbing items and 32 electrical supplies.
- **Default 0 Selection**: Start with 0 quantities and select only the items required on-site.
- **Mobile-First UX**: Touch-optimized steppers (`-`, `+`), collapsible site details, and swipeable category filters.
- **Slide-up Mobile Drawer**: Review selected items anytime with a sticky floating summary bar.
- **Direct WhatsApp Sharing**: Formatted 1-tap message sharing to suppliers, hardware shops, or clients.
- **Print & PDF Ready**: Clean A4 print stylesheet for official company estimation sheets.
- **CSV Export & Copy**: Easily export to Excel or copy to clipboard.
- **Custom Material Addition**: Add any unlisted job-site material on the fly.
- **Offline / Local Persistence**: Automatically saves draft state to local storage.

## 🛠️ Tech Stack
- HTML5
- CSS3 (BEM Architecture, CSS Variables, Responsive Grid & Flexbox)
- Vanilla JavaScript (Event-driven state management)

## 📦 Deployment
Deployable directly as a static site on Vercel, Netlify, or GitHub Pages.
